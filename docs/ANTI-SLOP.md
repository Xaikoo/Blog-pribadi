# Anti-Slop Baseline

This project follows the supplied `anti-slop-main` baseline as a quality gate.

## Enforcement
- Visual decisions require a purpose; Anti-Slop is not treated as a style guide.
- Real content only; placeholders are clearly labeled.
- Interactive controls must perform their stated action.
- Responsive behavior is designed from the start.
- Keyboard focus is visible and semantic landmarks are used.
- Motion is restrained and reduced-motion is respected.
- No fabricated testimonials, statistics, logos, social proof, or fake article content.
- No patch scripts that rewrite source/CSS after generation.
- Delivery claims require evidence: build/test/browser verification where applicable.

## Current baseline state
The repository begins with an intentionally honest empty content state. The content model is ready for real posts without manufacturing filler.
