# Blog Pribadi

Personal blog for Xaiko. Built as a monochrome editorial reading experience with an Anti-Slop quality baseline.

## Routes
- `/` — home
- `/writing` — writing archive
- `/about` — about
- `/posts/[slug]` — article route

## Development
```bash
npm install
npm run dev
```
